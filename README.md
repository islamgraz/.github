## 👋 About us

We are the technology team behind **islamgraz.org**. We build and maintain open, self-hosted software that helps our community stay informed, organised and connected — from prayer times on the mosque screen to membership and event management.

*Wir entwickeln und betreiben selbst gehostete Software, die unsere Gemeinde informiert, organisiert und verbindet.*

## 🧩 What we work on

| Project | Description |
|---|---|
| 📱 **Community App** | Mobile app for members — prayer times, announcements and events. Available on Google Play, iOS coming soon. |
| 🖥️ **[info-screen](https://github.com/islamgraz/info-screen)** | Kiosk display for the mosque: prayer times, announcements and schedules. |
| 🗂️ **Community management** | Membership tracking, Child Program (Mektab and Quran) enrollment, donations. |
| 📅 **Calendar** | CalDAV integration so community events show up in Calendar clients. |
